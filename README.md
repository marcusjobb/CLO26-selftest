# CLO26 — Selftest

Temastyrda "testa dig själv"-projekt för CLO26.

Varje mapp är ett eget projekt. Öppna mappen i VS Code, implementera metoderna i
`Easy.cs`, `Medium.cs` och `Hard.cs` och kör sedan `dotnet run` för att se hur långt du kommit.

---

## Projekt

| Mapp | Tema |
|------|------|
| `01-grundlaggande/` | Variabler, beräkningar, enkla loopar |
| `02-strangar/` | Stränghantering |
| `03-metoder/` | Metoder som anropar varandra |
| `04-algoritmer/` | Sortering, sökning, algoritmiskt tänkande |

---

## Hur man kör

```bash
cd 01-grundlaggande
dotnet run
```

## Regler

- Implementera metoderna utan Linq (om inte annat anges)
- Varje metod ska lösa exakt det problemet kommentaren beskriver
- Kör programmet och sikta på 100% per kolumn innan du går vidare till nästa
